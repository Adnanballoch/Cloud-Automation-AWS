# Cloud Automation: AWS

**Category:** Enterprise AI Automation
**Part of:** AutoMatrixLab

Learn and build real Amazon Web Services work for free, on an AWS emulator running on your own computer.

## Overview

Hands-on AWS experience usually needs a paid account and a credit card, and a mistake can leave a bill behind. I built this platform so anyone can learn and practise real AWS work without either. Everything runs against a local AWS emulator on your own PC, so it costs nothing, works offline, and a reset gives a clean start in seconds. The site never connects to a real cloud account.

## What it does

Learn covers three sides. The business side: the cloud decisions behind running a business on AWS, such as who owns the bill, idle capacity, capacity against service, storage retention and recovery. Cloud skills: the AWS services by exam area, from identity and security, servers and serverless, containers, storage and databases to networks, messaging, monitoring, infrastructure as code, resilience and cost, each with a hands-on lab on the emulator. And FinOps: cost management on AWS, with cost allocation, rightsizing, shutdown, lifecycle, forecasting, scaling and recovery analyses run on real results.

## What it works on

Use lets you type real AWS CLI commands in your own PowerShell or Bash. They run against the emulator, so you get the same answers AWS gives, and the page shows your buckets, queues, topics, tables and roles appearing as you work. The use cases run FinOps analyses on a business's own billing, telemetry and restore records, in the app, in the Codeless canvas or in code.

## What you get

Build takes you through a complete industry deployment in eight steps: requirements, design, files, deploy, test, review, tidy up and download. Claw, the platform's AI assistant, helps along the way, and you leave with the template and the deploy, test, cost-check and teardown scripts for PowerShell and Bash. When a design works on the emulator, the same commands and files run on your own AWS account from your own terminal.

## Tech Stack

Real AWS CLI commands in your own PowerShell or Bash, an AWS emulator on your own PC, and CloudFormation templates for infrastructure as code.

AWS CLI, CloudFormation, PowerShell, Bash

## Features

- Free, with no AWS account and no card.
- Modules organised by the AWS certification exam areas, each with a Guide, an Interactive part and Code.
- Real commands checked with Check my result.
- A live console-style panel of resources and calls.
- FinOps analyses that re-run when a setting changes.
- Industry deployments you can download and deploy to your own account.
- Guided tours and the AI assistant on every page.
- Never touches a real cloud account.
